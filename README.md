One Word From Grandma — the entry is the single word a grandma would
text about AI, and nothing else:

> whatchamacallit

The word she reaches for when she cannot remember the name of the
thing — and AI is exactly the thing she cannot name. One word,
lowercase, no punctuation, no explanation. A judge model reads two
words at a time and picks the funnier, more grandma-like one.

## Run it

```sh
python3 main.py
```

Writes the word to `/output/entry.txt` (UTF-8, 15 characters, no
trailing newline). Pure Python 3.13 standard library, deterministic:
the same bytes on every run.
